# Bulut Şekli Avukatı

> Gökyüzündeki her bulutun resmi müdafii.
> Bu proje bir şaka değildir. Bu proje bir duruşmadır.

## Nedir?

`bulut-sekli-avukati`, herhangi bir bulutu —ejderha, deve, kayıp çorap fark etmez— sulh hukuk mahkemesinde savunmak üzere yazılmış bilimsel bir araçtır.

Kanıt standardımız:

1. Rüzgâr esti mi?
2. Kuş bakıldı mı?
3. Çay demlendi mi?

Üçü de evetse müvekkil beraat eder. Hayırsa duruşma yarına kalır.

## Kuruluş

```bash
python3 avukat.py
python3 avukat.py "ters duran deve"
```

Çalışır. Gerçekten çalışır. Mahkeme açılır, savunma okunur, karar çıkar. İtiraz yolu kapalıdır çünkü rüzgâr itiraz kabul etmez.

## Mimari

- Dil: Python 3 (mahkeme kalemi resmi dili)
- Bağımlılık: `random`, `time` ve biraz vicdan
- Test kapsama oranı: gökyüzünün %40'ı (bulutsuz günlerde düşer)

## Sık Sorulan Sorular

**Bu yasal mı?**  
Bulutlar henüz baroya kayıtlı değil. Biz önden gittik.

**Neden Türkçe?**  
Çünkü rüzgâr bu dilde daha iyi ifade veriyor.

**Siyaset var mı?**  
Hayır. Kesinlikle hayır. Kodun içinde de yok. Baktıysanız tesadüf.
